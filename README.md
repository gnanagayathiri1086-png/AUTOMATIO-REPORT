# Predictive Analytics Using Historical Data

## Project Overview
This project focuses on analyzing historical business data and predicting future revenue trends using Microsoft Excel forecasting techniques. The dashboard converts raw data into meaningful insights through KPIs, charts, and predictive analysis.

## Objective
To build a predictive analytics dashboard that:
- Analyzes past performance
- Forecasts future revenue trends
- Displays business KPIs
- Provides insights for decision making

## Tools Used
- Microsoft Excel
- Forecast Sheet
- KPI Cards
- Charts & Visualizations
- Historical Data Analysis

## Features
✔ Total Revenue KPI  
✔ Total Orders KPI  
✔ Total Customers KPI  
✔ Predicted Revenue KPI  
✔ Revenue Trend Visualization  
✔ Forecast with Confidence Bounds  
✔ Key Insights Section  
✔ Interactive Dashboard Layout

## Project Workflow
1. Collect historical data
2. Clean and organize data
3. Create KPI calculations
4. Build charts
5. Generate forecast analysis
6. Create dashboard layout
7. Extract insights

## Outcome
The dashboard helps users understand business trends and supports future decision-making through predictive analytics.
